通过打德州扑克盈利 100 万美金，这个目标应该在每个牌手的愿望清单里出现过。我想开启一个耗时多年的挑战：通过征战线下中低额德州扑克，实现 100 万美金的盈利目标。作为一个有着几年牌龄的娱乐玩家，我目前积累了 1 万美金的 Bankroll，恰好是 2/3/5 级别 20 组的标准买入。我想看看自己需要多长时间能够实现这个梦想，也希望到那个时候，世界还没有巨变到金钱失去意义。

我的第一个挑战是：在本地赌场成为一名稳定的盈利玩家。说来也奇怪，我征战多个赌场均有盈利，唯独在这长期处于“水下”。似乎那里昏暗的灯光和不太新鲜的空气总会让我的竞技状态下滑，难以打出 A-Game。自身状态不佳也会影响所谓的“牌力庇佑”，可谓是打得差、跑得更差。我们的远大目标，就先从攻克这个家门口的难题开始，通过复盘解决技术漏洞，让它成为前往星辰大海的第一个里程碑。

当然，伟大的故事往往从苦难开始。昨天是多年以来重新打的第一个 session，以损失 3 个买入告终。在回程的路上，我仔细梳理了几手典型牌局。

## 客观复盘

### 1. SPR 的红线：操作是需要空间的

枪口位（UTG）Open 20，我持 <span class="pkr pkr-b">5♠ 6♠</span> 隔一位 3-bet 到 60。枪口随即 4-bet 到 200，他后手 Cover 我，我有 800。由于有位置优势，我选择跟注。翻牌发出 <span class="pkr pkr-b">J♠</span> <span class="pkr pkr-r">9♥ 5♥</span>，我中了底对并带有后门黑桃。我认为在这个面上我有所有的 <span class="pkr pkr-n">99</span>、<span class="pkr pkr-n">JJ</span>，面对他 150 的 C-bet，我判断自己能赢 <span class="pkr pkr-r">A♥ K♥</span>，且击中两对或补到黑桃可以反超其超对，于是跟注。转牌出一张黑桃 <span class="pkr pkr-b">2♠</span>，我成了底对+花抽。他直接 shoved 我剩下的后手，我根据赔率无奈跟注。河牌发出 <span class="pkr pkr-n">J</span>，他秀出 <span class="pkr pkr-n">KK</span> 收下底池。

**【实战教训】**
这一手牌我被所谓的“位置优势”蒙蔽了。在线下局，当 SPR（筹码底池比）降到 2 以下时，像 <span class="pkr pkr-n">56s</span> 这种靠隐含赔率活着的牌就成了废纸，此时跟注剥削的是自己。翻前跟注 200 之后，翻牌中了底对我就再也甩不掉，转牌中了后门花，赔率合适的情况下跟注倒是没有什么问题，但问题出在翻牌前。

### 2. 行为语言解码：反常必有妖

**【案例描述】**
我在后位 Open <span class="pkr pkr-n">QT</span> 不同花，两人跟注，大小盲也跟。翻牌 <span class="pkr pkr-n">A-3-5</span> 彩虹面。在我行动前，我身后的对手就提前做出了想过牌的动作。于是我选择过牌，大家 Check Around。转牌是一张 <span class="pkr pkr-n">J</span>，我形成卡顺听牌。此时我身后的对手再次“抢跑”想过牌。我判断大家牌力都弱，开始诈唬打 30（约半池）。奇怪的是，该对手随即 Raise 到 105。我怀疑他在演戏或诈唬，且我有卡顺，选择跟注，甚至盘算着河牌若他不中牌且下小注，我就 Check-Raise 偷池。河牌发出另一张 3。我过牌，他直接重注 300。我最终放弃了用 <span class="pkr pkr-n">Q-high</span> 强抓的念头。

**【实战教训】**
线下扑克很有趣的马脚，先示弱再示强的人手里往往拿着怪兽牌。连续两次“抢跑”过牌，那是教科书级别的诱导。他表现得越像没牌，就是越想让我去捅那个底池。在这种级别，极少有人会自编自演这么复杂的戏法来诈唬。我当时那种“他可能在偷我”的念头，纯粹是自作多情。

### 3. Blocker 的盲点：你大我认了

**【案例描述】**
我在枪口位（UTG）持 <span class="pkr pkr-r">K♥</span><span class="pkr pkr-b">K♠</span> Open 20，五人跟注进入翻牌，底池 100。翻牌发出 <span class="pkr pkr-r">A♥ 7♥ 6♥</span>。我选择过牌，后位的一名选手打了一个 80 的重注。此时一路弃牌到我，形成单挑。我认为一旦我买到红桃，对手可能会停手导致我拿不到价值。且我过牌跟注的行为太像买牌。因此我决定利用 <span class="pkr pkr-r">K♥</span> 作为 Nut Blocker 进行半诈唬，Raise 到 240。他 Tank Call。转牌没出红桃，我将故事讲到底，直接 All-in 后手 450。他纠结许久后跟注，河牌无红桃，他秀出 <span class="pkr pkr-n">A7</span> 两对。

**【实战教训】**
我用 <span class="pkr pkr-r">K♥</span> 阻挡了坚果同花，逻辑满分，但现实零分。我在阻挡坚果，但他通过下重注表示的是我有牌，本来我们 Check-Raise的意图是为了弃牌率，结果在进行过无声的交流后还选择这么做，确实是不会察言观色了，读空气的能力负100分。

### 4. 读牌的时效性：诈唬也需要牌神的庇佑

**【案例描述】**
我中位 Open <span class="pkr pkr-b">T♠ J♠</span> 到 20，下家跟注，SB 3-bet 到 105。基于该玩家平时尺度偏大，我认为这个较小的 3-bet 可能是 <span class="pkr pkr-n">AK</span>。我跟注看牌（后手 800）。翻牌 <span class="pkr pkr-n">7-7-2</span>，带一张黑桃。他 C-bet 65，我选择 Float，希望转牌能击中黑桃、T 或 J，或者在小牌面等他示弱时诈唬。转牌发出 <span class="pkr pkr-n">K</span>。他再次下注半池。虽然他翻前可能就是 <span class="pkr pkr-n">AK</span>，但由于他确实中了 <span class="pkr pkr-n">K</span>，我只能无奈弃牌。

**【实战教训】**
这是最讽刺的一手牌：我的 Read 成了我的诅咒。我读出他有 <span class="pkr pkr-n">AK</span>，这在翻牌是我的机会，但在转牌发出 <span class="pkr pkr-n">K</span> 之后，这就是我的催命符。

## 人间观察

如果只复盘到这里，我大概率到退休也没法实现我的星辰大海。线下扑克的魅力在于读人。当一个人带着他的人生阅历和认知坐在你面前时，德州扑克就不再是一个纯数学的游戏。死守 GTO 实际上是一种策略上的懒惰，真正的最佳策略是穿过对手的形象、举止、谈吐，去感受他此刻的情绪波动。像捕捉丈夫反常迹象的妻子一般，用心地分析他此刻的念头；用勇气去攻击他的恐惧；用宁静去接纳他的贪婪。

在第一手牌中，手持 <span class="pkr pkr-n">KK</span> 的是一个光头白人男性，五官立体，眼神犀利。他那种极其自律、不怎么入池的形象，像极了我隔壁组的 TL。他带着耳机刷 Youtube 时，我瞥见了他的屏幕——Lex Fridman 的播客。这满足了我对他“精英、稳健、风险厌恶”的人物画像。这样一个筹码极深、极其稳健的白领男对我进行 3 倍以上的 OOP 4-bet，到底有多大概率是 <span class="pkr pkr-n">AK</span>？这种人如果不拿 <span class="pkr pkr-n">AA</span>/<span class="pkr pkr-n">KK</span>，大概率是不会在这个尺度上玩命的。

第二手和第三手牌的对手，是一个邋里邋遢的中年大叔，长得极像《植物大战僵尸》里的房主疯狂戴夫。他那台杂牌手机亮度拉满，亮到我能轻易看到他在和情人发短信。前五分钟两人还在互诉衷肠，五分钟后对面就开始喷 “wtf” 说 “you hate me”。这样生活在混乱关系中的人，当他愿意往底池里放筹码时，他怎么可能轻易放弃？底池于他而言，就像那段糟糕的关系，即便是一条沉船，他也要跟着沉下去。

最后一手牌的对手是一个亚洲男性，大概率是同胞，因为我听到了他手机里点开的小红书外放的中文。他戴着口罩，在游戏手牌中间，眉间偶尔锁出沟壑，思考之后再做动作。我甚至能脑补出他读硕、转码、加入大厂、定投指数基金的人生路径。这样的人思考严谨、规避极端风险，在 SPR 较高时利用范围诈唬他本是有利可图的，只可惜牌神并没有站在我这一边。

这些观察往往是在对局后才由点成面的。形成这种“人物画像”的能力，对我实现百万挑战至关重要。输钱时少输，赢钱时多赢，所有的正确判断都藏在这些细节的倾向性里。

希望伟大的故事才刚刚开始。
